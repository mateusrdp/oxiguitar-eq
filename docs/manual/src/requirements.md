# Requirements and assumptions

## Requirements

- OxiGuitar 0.20 or later (plugin interface 1.8). See [the OxiGuitar manual](https://mateusrdp.github.io/oxiguitar/). Version 0.2 of the plugin works with OxiGuitar 0.14 and later.
- Windows, macOS or Linux.
- A plugin that plays the track, since the equalizer shapes sound that another plugin makes.

## Assumptions

- You set it by ear. There is no analyser and no presets.
- Settings belong to the track and are saved beside the score. The score itself doesn't change.
