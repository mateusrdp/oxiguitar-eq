# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- **Every test with one command** (mateusrdp/oxiguitar#273): `scripts/test-all.py` builds and runs all of this repository's tests, and tests the plugin against the newest OxiGuitar release, with a progress bar, a summary to paste into an issue and a log to diagnose from. The manual has a Features page naming the tests of every feature (CI checks it) and a Testing page.

### Changed

- **The manual explains the ideas behind the plugin** (its overview, with pictures), shows how to use it with screenshots, says in Architecture and strategy what it can't do yet, what is left out on purpose and where help is wanted, and has a Credits page listing every project it uses, with links and thanks. The README has a plain-words introduction and a Credits section.

## [0.3.0] - 2026-11-16

### Changed

- **The equalizer says where it goes in a track's chain**
  (mateusrdp/oxiguitar#293): `"order": 300` on the effect, plugin interface
  1.8. OxiGuitar no longer keeps a list of plugin ids for the default order
  of a track's effects; each effect's manifest says it (pedals 100, amp
  models 200, equalizers 300), and the Track tab's arrows still change it
  for a track. The plugin now needs OxiGuitar 0.20.0 or later (interface
  1.8), whose tag the SDK comes from.

### Added

- **Knowledge graph analysis** (Understand Anything): the `.ua/knowledge-graph.json` captures the project's architecture — 40 nodes, 53 edges across 6 layers and a 9-step guided tour — for navigation and documentation. Generated by the `/understand` command.

## [0.1.0] - 2026-11-04

### Added

- The effect `eq` (mateusrdp/oxiguitar#152): an equalizer after a track's
  instrument, for every class of instrument, with or without an amp model.
  Off (the default), **Basic** (Bass, a low shelf at 120 Hz; Middle, a peak
  at 700 Hz, Q 0.8; Treble, a high shelf at 3.2 kHz) or **Graphic** (ten
  peaks one octave apart, 31 Hz to 16 kHz, Q 1.41); every band −12 to
  +12 dB in half-decibel steps. Both modes keep their values; only the one
  picked plays. Kept per track in the song's `.oxg` file under
  `oxiguitar.eq`. Robert Bristow-Johnson's cookbook biquads, our own code;
  no latency.
- The track dialog's section **Equalizer**, for every track: the mode (Off,
  Basic, Graphic), a slider per band of the mode picked, and **Flat**,
  which sets that mode's bands to 0 dB.
- `build-oxp.sh`, the contract test and the real-time checks through
  OxiGuitar's plugin host (`tests/contract.rs`), and the release and publish
  workflows (oxiguitar's at v0.12.1).
